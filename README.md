# Manus Car Multimarcas — site

Site de uma página (Astro + Tailwind). Todo o conteúdo fica em `src/data/`.

- `npm run dev` — desenvolvimento
- `npm run build` — build de produção em `dist/`

Pendências marcadas como `TODO(dono)` no código: serviços, Instagram/site, logo e cores, slogan, texto "Sobre", fotos (`images/`), avaliações, domínio e indexação (`SITE_INDEXABLE`).
